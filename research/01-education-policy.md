# 01 — Education policy sources (syllabus area 1, plus ECCE for area 3)

Researched 2026-10-09. Every URL in the main table was checked with `curl -sIL` on that date and returned **HTTP 200, `application/pdf`**. The size column is the Content-Length the server reported (MB = MiB). No files were downloaded.

**Important context:** In 2025–26 the Ministry of Education moved its sites. Old links on `education.gov.in/sites/upload_files/mhrd/files/...` and `dsel.education.gov.in/sites/default/files/...` now return **404**; this includes the well-known `NEP_Final_English_0.pdf` link. The Department of School Education & Literacy (DoSEL) now serves files from **`dsel-education.gov.in/static/uploads/...`** under hashed file names. I matched each hashed file to its title using the DoSEL listing pages (Acts & Policies, Guidelines, Publications, Reports), and the Content-Length of each file matches the size printed on its listing.

## Gaps / notes

- **Samagra Shiksha Framework for Implementation (latest version, with Programmatic & Financial Norms): NOT VERIFIED.** The canonical link is `https://samagra.education.gov.in/docs/ss_implementation.pdf`. Search results confirm it holds the "Programmatic and Financial Norms" chapter and an Output-Outcome Monitoring Framework annex for 2022-23. But the host `samagra.education.gov.in` (164.100.166.225) timed out on every attempt, in both curl and a browser, so it is probably geo-restricted or down. The candidate should open it from an Indian network. The DoSEL Samagra page (https://www.dsel-education.gov.in/offerings/schemes-and-services/details/samagra-shiksha-QzM4gTMtQWa) carries only the amendment and FMP files. Also note the scheme period ended 31.03.2026; check for a notified Samagra Shiksha 3.0 or extension framework in the current-affairs sweep (area 7).
- **FMP-2024 manual** is referenced at `DSEL.EDUCATION.GOV.IN/sites/default/files/update/FMP_2024.pdf`, but that path pattern is now 404. I found no new link for it.
- **National ECCE Curriculum Framework (MoWCD, 2014)** is only listed on `wcd.nic.in`: `https://wcd.nic.in/sites/default/files/national_ecce_curr_framework_final_03022014%20(2)_1.pdf`. That host, and `nipccd.nic.in` (which has the ECCE Task Force report), timed out, so these are unverified. NCF-FS 2022 and Aadharshila/Navchetana 2024 supersede it in practice.
- **Poshan Bhi Padhai Bhi:** there is no standalone "guidelines" PDF. The launch-event document, the ECCE-day guidelines and the PIB releases are the official sources.
- **NIPUN Bharat Hindi guidelines:** none found. Guessed DIKSHA Hindi file names return an HTML stub, not a PDF. `nipunbharat.education.gov.in` was unreachable.
- **PARAKH:** the national report is a short summary (2.4 MB). District reports are listed at https://parakh.ncert.gov.in/prs-reports-2024-districtlist and dashboards are at https://dashboard.parakh.ncert.gov.in/
- **NIEPA:** I found no NIEPA national summary of NEP as a PDF. NCSL-NIEPA (ncsl.niepa.ac.in) hosts only state school-leadership plans. For official NEP summaries use the DoSEL "2 Years of NEP" booklet, the MoE Annual Report 2024-25 (it has NEP implementation chapters) and the NEP text itself. The PIB "Salient Features of NEP 2020" release (PRID 1642061) returned HTTP 401 to curl, though it should open in a browser.
- **Which version to read:** for NCF-SE prefer the NCERT May 2026 file and confirm in the foreword whether it is a revised edition. For UDISE+ and PGI, use 2025-26, the latest as of Oct 2026.
- Some extra items found along the way may suit other areas: Swachh evam Harit Vidyalaya Rating (SHVR) guidelines 2026 (English: https://dsel-education.gov.in/static/uploads/2026/08/11d9facc71295d768cfd751ba69a7ae9.pdf, 20.0 MB), and the PARAKH Equivalence of Boards report (https://parakh.ncert.gov.in/sites/default/files/2025-08/Equivalence_of_Boards_Report.pdf, 144.5 MB).
